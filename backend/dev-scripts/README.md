# Development & Testing Scripts

This folder contains experimental, testing, and development scripts for the SoilHelp ML backend.

## Training Scripts
- **retrain_cnn_quick.py** - Quick CNN retraining
- **retrain_cnn_v2.py** - CNN v2 retraining experiments
- **retrain_npk_advanced.py** - Advanced NPK model retraining
- **train_custom_cnn.py** - Custom CNN architecture training
- **train_simple_cnn.py** - Simple CNN training

## Testing Scripts
- **test_ai_endpoints.py** - Test AI API endpoints
- **test_ai_integration.py** - Test AI integration
- **test_cnn_real.py** - Test CNN on real data
- **test_cnn_v2.py** - Test CNN v2
- **test_gemini_setup.py** - Test Gemini API setup
- **test_quality_checker.py** - Test image quality checker

## Diagnostic Tools
- **diagnose_images.py** - Image diagnostics
- **quick_accuracy_test.py** - Quick accuracy checker
- **quick_demo.py** - Quick AI demo

## Demo
- **ai_demo.html** - Standalone HTML demo for AI features

---

**Note:** These scripts are for development only and are NOT part of the production deployment.
